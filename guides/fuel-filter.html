ALH REFERENCE GUIDE

Fuel Filter / Air-in-Fuel Checks

Air ingress is a common starting point when an ALH exhibits poor starting or fuel starvation symptoms.

Workflow

  1. Inspect the fuel filter, thermostatic tee, seals and hoses for leaks or improper seating.
  2. Replace the filter and seals according to the vehicle-specific procedure.
  3. Prime the system using an appropriate clean method rather than repeatedly cranking a dry injection system.
  4. Inspect transparent fuel lines if fitted for excessive bubbles.
  5. If the symptom remains, check supply restriction, return flow and injection-pump condition.

Important note

Keep dirt out of the VE injection system. Use clean diesel-system practices throughout.
