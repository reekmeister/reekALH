ALH REFERENCE GUIDE

ALH Timing Belt — Planning & Verification

A high-level workflow for preparing, locking, replacing and verifying the timing drive. Use the factory procedure for exact fasteners, tool positions and model-year variations.

Workflow

  1. Confirm engine code and vehicle application before ordering parts/tools.
  2. Support the engine correctly and expose the timing-drive area according to the factory procedure.
  3. Use the specified locking/holding tools for crankshaft, camshaft and injection pump; do not rely on paint marks as the primary timing reference.
  4. Replace the belt-system components required by the chosen service kit and inspect seals, coolant pump and mounts while access is available.
  5. Rotate the engine by hand as specified by the factory procedure, re-check alignment, then perform injection-timing verification with VCDS on the VE/ALH system.

Important note

The ALH is a VE-pump TDI. Ross-Tech documents using Engine → Measuring Blocks → Group 000 → Basic Settings and the TDI Timing function with coolant above 85°C for injection-timing verification.
